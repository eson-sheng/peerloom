# 语音与同播回归

麦克风独立使用 voice 会话；屏幕、摄像头、本地音视频同播使用 media 内容会话。
同一房间只允许一个内容分享者，但有媒体席位的成员均可开启语音。
停止内容共享保留麦克风；退出媒体区、禁用媒体权限或退出房间同时释放两种媒体。
界面麦克风按钮控制自己的发送静音，成员语音按钮控制本地是否收听该成员。
新成员加入时应同时收到已有语音与内容会话。

部署需同时更新前后端并让所有参与者刷新页面；旧客户端没有独立语音会话支持。

真实设备验收（A 房主，B 受邀成员；推荐分别戴耳机）：

1. A 开麦，再邀请 B；B 开始本地视频同播。A 能看到视频，B 能听见 A。
2. B 也开麦，两人互相听见；双方自己的麦克风静音/恢复不影响同播。
3. B 暂停、恢复、拖动、结束视频；结束后 A/B 语音继续。随后 A 可接手同播。
4. A 共享屏幕时 B 不能抢占内容，页面提示已有共享；A 结束后 B 可同播。
5. 同播中加入 C：能观看内容并听见已有语音；自动播放受阻时有“点击收听”入口。
6. B 退出媒体区或 A 禁用 B 媒体权限：B 语音及内容停止，其他成员不退出。
7. 席位不足、权限关闭、浏览器不支持捕获、文件解码失败：有明确提示，不假装开始成功。
8. 同播被拒绝或启动超时：只释放新内容采集，已有麦克风继续。
9. 共享屏幕时拒绝麦克风权限：屏幕继续，点击麦克风可重试。

自动测试使用模拟设备/信令，不代表已验收真实声音、系统音频捕获、浏览器权限弹窗或跨网络 TURN。
